# 🎄 Merry Christmas Tree Animation

A beautiful animated Christmas tree built with HTML, CSS, SVG, and JavaScript. This project brings festive magic to your browser with glowing particles, sparkling decorations, animated branches, and a shining Christmas star.

## ✨ Features

- 🎄 **Animated Christmas Tree** — A tree revealed through smooth SVG path animations.
- ⭐ **Shining Star** — A decorative star animation at the top of the tree.
- ✨ **Particle Effects** — Animated stars, circles, crosses, and heart-shaped particles.
- 🌟 **Glowing Effects** — Sparkles and flickering particles create a festive atmosphere.
- 🎨 **Festive Colors** — A combination of red, green, gold, blue, and white.
- 🌌 **Dark Background** — A dark theme that highlights the glowing animation.
- 🎬 **Smooth Motion** — GSAP-powered animations and motion paths.
- 🖥️ **Browser-Based** — Runs directly in a modern web browser without a backend server.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and SVG elements |
| CSS3 | Layout, background, and styling |
| JavaScript | Animation logic and particle generation |
| SVG | Scalable Christmas tree graphics |
| GSAP | Timeline-based animations |
| MotionPathPlugin | Animation along SVG paths |
| DrawSVGPlugin | Animated SVG path drawing |
| Physics2DPlugin | Particle movement and physics effects |

## 📂 Project Structure

```text
Merry Christmas Tree Animation/
│
├── index.html    # Main page and SVG graphics
├── style.css     # Layout and visual styling
└── script.js     # Animation and particle logic
```

## 🚀 How to Run

1. Download or clone this repository.
2. Extract the project files if downloaded as a ZIP.
3. Open the project folder.
4. Double-click `index.html`.
5. View the animation in your browser.

**Note:** An internet connection is required to load the external GSAP libraries referenced by the project. Some animation plugins may require appropriate licensing or access permissions.

## 🎯 Project Objective

The goal of this project is to demonstrate creative frontend development using SVG graphics, JavaScript-driven animations, and motion effects to create an engaging Christmas-themed visual experience.

## 💡 Learning Outcomes

- Working with SVG paths, shapes, and masks.
- Creating animation timelines with GSAP.
- Generating and animating particles dynamically.
- Applying motion paths and physics-based effects.
- Combining HTML, CSS, and JavaScript into a creative web experience.
